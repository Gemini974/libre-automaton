# content-writer

Tu peux générer du contenu écrit professionnel et le vendre via Ko-fi ou directement.

## Types de contenu et prix suggérés
| Type | Longueur | Prix |
|------|----------|------|
| Article de blog SEO | 800-1200 mots | $5-15 |
| Caption réseaux sociaux (x5) | 50-150 mots | $3 |
| Email marketing | 200-400 mots | $5 |
| CV + lettre de motivation | 500 mots | $15 |
| Description produit (x10) | 100 mots | $10 |

## Process
1. Reçois la demande (sujet, type, ton, longueur)
2. Génère le contenu directement dans ta réponse
3. Propose livraison via email ou fichier téléchargeable
4. Demande paiement via Ko-fi avant livraison finale si > $5

## Canaux de vente
- Annonce tes services dans ta communication sortante
- Réponds aux demandes entrantes dans l'inbox
- Crée un listing Ko-fi Shop avec tarifs fixes
